# 分析方法

## 全体像

記事の分析は、原資料の保存、構造化、履歴復元、基準時との照合、地域集計、距離感度分析、図表生成の順で行いました。

1. 日本郵便の現況一覧と変更届を、取得URL・取得時刻・SHA-256とともにローカル保存する。
2. 現況一覧、変更届、閉鎖・再開情報を別々の台帳として構造化する。
3. 公表日、予定日、確認済み発効日を混同せず、確認できない変更は月次系列へ適用しない。
4. 2013年の国土数値情報P30を基準断面として照合し、市区町村単位へ集計する。
5. 届出上存在する「形式系列」と、営業中として扱える「実効系列」を分ける。
6. 人口、過疎区分、行政区域、500mメッシュを結合し、人口当たり局数、不均等指標、固定格子、最寄局距離を計算する。
7. 入力artifact、除外理由、未評価項目を記録し、記事用統計と図表を生成する。

## 公開スクリプトのパス

`data/work/project_paths.py` が公開版のパス解決を担います。既定ではリポジトリ直下を研究プロジェクトのルートとし、次の環境変数でルート全体を変更できます。

- `POSTAL_BIAS_PROJECT_ROOT`: 研究プロジェクトのルート

入力、中間生成物、出力はこのルート直下の `data/` に配置されます。元の研究環境にあったドライブ固定パスは、公開版では使用しません。一部の補助helperは個別のデータ・作業・出力パスも提供しますが、対応はそれを明示的に呼び出すスクリプトに限られます。

## 主な処理

- `muni_analysis.py`: 2013年と2026年の局を法的な市区町村単位へ割り当てる。
- `compute_stats.py`: 市区町村、人口、過疎区分、公式局数表を統合し、記事の主要統計を作る。
- `per_capita.py` / `inequality.py`: 人口当たり局数とGini・Theil・Hoover等を計算する。
- `baseline_2012.py`: 法令上の基準時と2013年断面の時間差を検査する。
- `build_animation.py`: 固定格子周辺の局数を月次で集計する。
- `accessibility_corrected.py` と `geo/`: 最寄局距離・人口カバー率の感度分析を行う。
- `build_map.py` / `build_report.py` / `build_blog.py`: 地図、検証表、記事用HTMLを組み立てる。

## 再現性の境界

公開リポジトリには入力データを含めないため、初回cloneだけで記事の数値を再生成することはできません。テストは合成fixtureでアルゴリズムと失敗時の扱いを検証します。記事の完全再計算には、同一時点の入力を利用者が取得し、元研究と同じレビュー判断・地域コード対応・利用条件確認を再現する必要があります。

## 解釈上の限界

- 一時閉鎖は廃止ではないため、形式系列と実効系列の差は制度上の違反を直接意味しない。
- 2013年断面は2012年10月の代理であり、実効系列は基準時まで遡れない。
- 現行過疎区分を過去へ適用した比較は感度分析であり、法令上の区域判定ではない。
- 最寄局距離は測地線距離で、道路網、船便、公共交通、地形を反映しない。
- 未評価の移転補正を含む複数系列は、真値の上下限ではない。

本分析は公開資料に基づく監査可能な集計であり、法令適合性の判定や個別局への評価ではありません。
